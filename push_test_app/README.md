# Тестовое веб-приложение для Push-уведомлений

Это веб-приложение предназначено для тестирования отправки push-уведомлений через Firebase Cloud Messaging (FCM) в режиме реального времени. Приложение позволяет получать FCM токены устройств и отправлять тестовые уведомления для проверки работоспособности системы.

## Возможности

- Получение FCM токена устройства
- Отправка тестовых push-уведомлений на конкретное устройство
- Отправка уведомлений на темы (topics)
- Настройка дополнительных данных для уведомлений
- Тестирование различных типов бизнес-уведомлений (получение денег, активация аккаунта и т.д.)
- Просмотр логов отправки и получения уведомлений

## Установка и запуск

### Предварительные требования

- Python 3.8 или выше
- Файл учетных данных Firebase (`serviceAccountKey.json`)
- Docker и Docker Compose (опционально)

### Запуск с использованием Docker

1. Убедитесь, что у вас установлены Docker и Docker Compose
2. Поместите файл `serviceAccountKey.json` в директорию `credentials/`
3. Запустите приложение с помощью Docker Compose:

```bash
docker-compose -f docker/docker-compose.webapp.yml up --build
```

4. Откройте браузер и перейдите по адресу `http://localhost:8004`

### Запуск без Docker

1. Установите зависимости:

```bash
pip install firebase-admin flask flask-cors
```

2. Убедитесь, что файл `serviceAccountKey.json` находится в корневой директории проекта или в папке `credentials/`

3. Запустите веб-сервер:

```bash
python -m push_test_app.server
```

4. Откройте браузер и перейдите по адресу `http://localhost:8004`

## Использование веб-приложения

1. Откройте приложение в браузере
2. Нажмите кнопку "Запросить разрешение" для получения FCM токена устройства
3. Сформируйте тестовое уведомление:
   - Укажите заголовок и текст уведомления
   - Добавьте дополнительные данные в формате JSON (опционально)
   - Добавьте URL изображения (опционально)
   - Выберите отправку на конкретное устройство или на тему
4. Нажмите кнопку "Отправить уведомление"
5. Отслеживайте статус отправки и получения в разделе логов

### Примеры тестовых уведомлений

В приложении есть готовые шаблоны для различных типов уведомлений:

- **Получение денег** - уведомление о поступлении средств на счет
- **Отправка денег** - уведомление об отправке перевода
- **Активация аккаунта** - уведомление об успешной активации аккаунта
- **Изменение статуса** - уведомление об изменении статуса клиента

## Настройка Service Worker

Файл `firebase-messaging-sw.js` должен находиться в корне вашего веб-приложения для обработки уведомлений в фоновом режиме. В данном проекте этот файл уже подготовлен и обслуживается через Flask.

## Устранение неполадок

### Не получается получить FCM токен

- Убедитесь, что сайт работает по HTTPS или на localhost
- Разрешите уведомления в настройках браузера
- Проверьте консоль браузера на наличие ошибок

### Уведомления не приходят

- Проверьте правильность файла учетных данных Firebase
- Убедитесь, что FCM токен указан верно
- Проверьте статус отправки в логах сервера

### Ошибка инициализации Firebase

- Убедитесь, что в проекте есть файл учетных данных Firebase
- Проверьте конфигурацию Firebase в файле `firebase-init.js`
- Проверьте, что у проекта Firebase включена функция Cloud Messaging
