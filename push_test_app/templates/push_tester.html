Тестирование Push-уведомлений

Это приложение позволяет протестировать отправку push-уведомлений через Firebase Cloud Messaging.

Получите токен вашего устройства и отправьте тестовое уведомление, чтобы проверить, работает ли система корректно.

FCM Токен устройства

Отправка тестового уведомления

Если не указан, будет использован токен, полученный выше.
JSON объект с дополнительными данными для уведомления.

Логи

Примеры использования разных типов уведомлений

Доступные типы уведомлений:

  • receive-money - Получение денег
  • send-money - Отправка денег
  • account-activated - Активация аккаунта
  • client-status-changed - Изменение статуса клиента
